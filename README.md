# ReadEase – Student Readability Analyzer

An interactive readability tool designed to make reading analysis accessible and actionable for students and educators.

## ✨ Features
- **Age-Adaptive Scoring:** Compares text difficulty against the user's specific age and reading level.
- **Smart Sentence Breakdown:** Pinpoints difficult sentences and explains *why* they are tough to read.
- **Plain-English Simplifications:** Provides one-click alternative phrasings for dense, complex sentences.
- **Comprehensive Readability Metrics:** Computes Flesch-Kincaid, Gunning Fog, SMOG, Coleman-Liau, and ARI under the hood.
- **Zero-Dependency Architecture:** Built with pure HTML5, CSS3, and modern JavaScript for maximum speed and privacy.

## 🛠️ Tech Stack
- **HTML5 & CSS3** (Responsive design, CSS variables, glassmorphic UI)
- **JavaScript (ES6+)** (Readability algorithms, syllable counter, text-simplification engine)
